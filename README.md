EME Predictor (Windows Standalone, currently not working for macOS)

Built with: MATLAB R2025b

Requires: MATLAB Runtime R2025b (version 25.2), Windows 64-bit. MATLAB Runtime is free and is required to run this standalone app.
(Users do NOT need a MATLAB license.)

INSTALL
1) Run the installer (EME_Predictor_Installer.exe). Windows defender may identify the file as a threat, in which case click "run anyway".
2) If prompted, allow installation of MATLAB Runtime R2025b (25.2)
3) Launch “EME Predictor” from the Start Menu
NOTE: You will need administrator rights to run the installer. 

If MATLAB Runtime 25.2 is already installed, you may also download the folder "Application" and run the app from there. 

NOTE: The app is slow to launch but will load after approximately 1 minute.

Tip: use the file "Example input file.xlsx" to test the app.
